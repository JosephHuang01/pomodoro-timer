# Pomodoro Timer Sub-site

This folder is self-contained and can be published as a static sub-site. `index.html` is the entry point; its stylesheet and JavaScript modules are alongside it.

## Publish with GitHub Pages

If the repository publishes from the `main` branch and repository root, commit and push this folder with the rest of the repository. GitHub Pages will serve it at:

<https://josephhuang01.github.io/pomodoro-timer/pomodoro%20timer/>

No build step is required. Keep the folder name `pomodoro timer` so the URL remains consistent.
